# 32. 微信登录

使用：

```text
Taro.login()
```

流程：

```text
微信小程序
↓
获取 code
↓
POST /api/auth/wx-login
↓
后端调用微信接口
↓
获取 openid / unionid
↓
查询用户
↓
不存在则创建
↓
生成 JWT
↓
返回 Token
```

微信：

```text
WX_APP_ID
WX_APP_SECRET
```

只能配置在服务端。

禁止出现在：

```text
React
Taro
前端配置
Git
```
